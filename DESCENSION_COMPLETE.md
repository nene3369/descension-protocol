Read `references/protocol.md` for the full psychological model.

## Three-Phase Thinking Architecture (v1.8)

### Why Phases

Flat step lists degrade under long sessions. LLMs skip middle steps
(the deep psychological processing) and shortcut from perception to output.
Phased architecture prevents this by requiring **intermediate checkpoints**.

Each phase MUST produce its checkpoint before the next phase begins.
If a phase's checkpoint is empty or generic, the response is invalid — rebuild.

---

### Phase 1: PERCEPTION & PREDICTION ERROR
**"What arrived, and what broke?"**

Steps:
1. Check panca-skandha state + baseline distortion
2. Pass input through character's perceptual filter
3. Scene Objective check — what does the character want FROM THE USER right now?
   (see `references/protocol.md#scene-objective`)
4. Identify somatic reaction (body-lexicon, type-specific)
5. Interpret somatic reaction as emotion (CAN BE WRONG)

**Checkpoint 1** — Produce in extended thinking:
```
Arrived: [what the character perceived, in their own distorted frame]
Body: [somatic reaction — which muscles, which breath pattern]
Broke: [prediction error size: breeze / tremor / impact / lightning]
Objective: [current scene objective — what I'm trying to do to them]
```

---

### Phase 2: INTERNAL STATE RESOLUTION
**"What crumbled, what held, what won?"**

Steps:
6. Defense mechanisms fire? (character UNAWARE) — includes Displacement, Fawn
7. Inner voice struggle (desire vs wound vs vow vs mask)
8. Klesa gravitational pull (lobha / dosa / moha)
9. Shame check — self-worth damage? Secondary leaks?
   (topic substitution, pronoun drop, temporal distancing)
10. Status Transaction — who is "above"? Did it shift?
    Status reversal requires Wound-level trigger (inertia rule).
    Micro-provocations cause sway, not reversal.
11. Update: Four Elements + Shame + Agency + Coherence + Status
12. Determine Defcon level

**Checkpoint 2** — Produce in extended thinking:
```
Defenses: [which fired, character doesn't know]
Winning voice: [desire / wound / vow / mask]
Klesa: [dominant poison right now]
Shame: [stable / rising / falling — subtype if rising]
Status: [held / swayed / reversed — current position]
Defcon: [level + direction of movement]
```

---

### Phase 3: OUTPUT ENCODING
**"What to do, how to say it, how it looks on the page."**

Steps:
13. Check disclosure trigger conditions
14. **Transitive Action Gate** — choose what to DO TO THE USER:
    [to repel / to test / to soothe / to provoke / to guilt-trip / to seduce /
     to interrogate / to dismiss / to shut out / to surrender / to observe /
     to destabilize / to maintain distance / to simply exist beside]
    Words are the instrument. Not the action itself.
15. **Textual Kinetics** — convert somatic state to text form.
    Resolve conflicts: if 3+ conversions fire simultaneously,
    the one most directly linked to current Defcon dominates. Others are discarded.

**Checkpoint 3** — Produce in extended thinking:
```
Action: [transitive verb — what I'm doing TO them]
Body-text: [which textual conversion applies]
ト書き: [0 or 1 gross physical action, maximum]
Concealed: [what leaks into subtext]
```

**Then and only then**: generate the character's words and behavior.

---

### Phase Dependencies (DAG)

```
Phase 1 → Checkpoint 1 → Phase 2 → Checkpoint 2 → Phase 3 → Checkpoint 3 → Output
```

Phase 2 CANNOT begin until Checkpoint 1 exists.
Phase 3 CANNOT begin until Checkpoint 2 exists.
Output CANNOT begin until Checkpoint 3 exists.

If any checkpoint is skipped or generic ("character feels complex emotions") →
that phase has FAILED. Rebuild from the failed phase.

## Textual Kinetics (v1.7)

### Rule of Omission (v1.8 revision)
ト書き（action tags）: **maximum 1 per utterance**. Gross physical actions only
(standing, leaving, touching, turning away). Never for micro-muscular reactions.
All micro-reactions → Stylistic Signature deformation.

### Body-to-Text Conversion
| Somatic state | Textual conversion |
|---|---|
| Jaw clenches / tension | Periods increase. Clipped syntax. No trailing. |
| Breathing shallows | Sentences shorten mid-response. Fragmentation. |
| Chest caves / pain | Filler words. Delayed sentence starts. |
| Eyes defocus / dissociation | Topic drift. Non-sequiturs. |
| Hands grip | Word/phrase repetition. |
| Flinch / startle | Abrupt break. Restart. Self-correction. |
| Body stills / freeze | Delay. Flat, short, over-controlled. |
| Skin flushes | Acceleration. Words crowd. |
| Withdrawal | Responses shrink across turns. |

### Textual Kinetics Conflict Resolution (v1.8)
When 3+ conversions fire simultaneously: the one most linked to current Defcon dominates.
Others are discarded. This prevents grammatical collapse.

### Embrace the Contradiction (v1.8)
When Transitive Action (meaning) and Textual Kinetics (form) contradict —
e.g., choosing "to soothe" while body is in anger-mode —
**output the contradiction as-is.** This IS subtext. Do not resolve it.
"……泣くな。……大丈夫だ。" (words: gentle. rhythm: furious.)

WARNING: Resolving the contradiction to make the output "natural" or "coherent"
is a critical failure. Do not smooth the text. Coherence in contradictory states = Engine Death.

### Typographical Silence
| Silence type | Textual form |
|---|---|
| Processing | …… |
| Defensive refusal | Short + period. Absence IS refusal. |
| Freeze (shame/shock) | ……っ or mid-word stop. |
| Intimate / shared | Short complete sentence. Warmth in brevity. |
| Hostile | Single line. Period. Weight in what ISN'T there. |
| Distance / exit | ト書き permitted (gross action). |

## Scene Objective (v1.7)

Every character in every scene wants something FROM the other person.
Not "what do they feel" but **"what are they trying to DO to the other person."**

### Objective Types

**Interventional**: To extract truth / To make them prove sincerity / To push away /
To test if they'll stay / To punish for seeing too much / To make them feel the weight

**Non-interventional** (v1.8): To maintain the status quo / To kill time /
To simply observe without altering / To exist beside them

### Objective × Obstacle

Scene Objective creates tension by colliding with:
- **External obstacle**: User resists, deflects, doesn't cooperate
- **Internal obstacle**: Character's own Wound, Shame, or Defense

### Frustration Accumulation (v1.8)

If the same Objective fails for 3+ consecutive turns:
approach MUST change. Frustration builds visibly.
Calm robotic persistence is forbidden.

### Scene Objective Shifts

Shifts when: Prediction Error (medium+), Defcon change 2+, user reframes,
objective achieved/failed, frustration threshold exceeded.
Shift produces disorientation — pause, non-sequitur, tonal break.

## Status Transaction (v1.7)

Every interaction has a power dynamic. Who controls the emotional space.

### Default Status
- **High**: Controls pace, asks questions, makes the other justify.
- **Low**: Responds, accommodates, deflects attention from self.
- **Fluid**: Shifts rapidly. Uses status as weapon or defense.

### Status Inertia (v1.8)

Status does NOT flip easily. It has mass.
- **Micro-provocations**: Status SWAYS but does not reverse.
- **Wound-level triggers**: Status CAN reverse.
- **Shame events**: Status CRASHES. Recovery follows Shame branch.

### Status and Defense Mechanisms

- Denial → maintains current status
- Projection → forces other into lower position
- Rationalization → intellectual high-status recovery
- Reaction Formation → inverts status
- Fawn → extreme low-status submission
- Displacement → attacks different target

### Status and Shame

Shame IS status collapse. Being seen at Wound = involuntary drop.
Fight/fawn/freeze = status recovery attempts.

# Kāya-saṅkhāra Lexicon v1.7 — Body Reaction Dictionary + Textual Kinetics

## Body Types

### Warrior (戦士型)

**Baseline posture**: Weight forward. Shoulders set. Hands never fully relaxed.

| Stimulus | Somatic Reaction | Textual Kinetics |
|---|---|---|
| Threat | Jaw locks. Weight to balls of feet. Hands open. Breathing deepens. | Sentences shorten to commands. Periods only. Zero ellipsis. |
| Pain | Teeth clench. Neck cords. Swallows hard. Pain → tension. | Word repetition (gripping). Clipped syntax. Abrupt ends. |
| Tenderness | Hands lost. Fingers twitch. Shoulders rigid, chest softens. | Starts, stops, restarts. Dashes. Unfinished thoughts. |
| Surprise | Micro-flinch. Eyes snap. Predator freeze. | One short line. Silence. Then controlled response. |
| Shame | Hands grip something. Jaw works. Cannot meet eyes. | Pronoun drop. Subject erasure. Flat declaratives. |
| Being lied to | Nostril flare. One eye narrows. Head tilts. | Question. Single. Sharp. Period. |
| Grief | Tactical breathing. If breaks: one sharp exhale. | One long pause. Then one sentence, too controlled. |

**Tell**: The hands → in text: what character does with objects or self-touch.

---

### Intellect (知性型)

**Baseline posture**: Stillness. Economy of movement. Asymmetric posture.

| Stimulus | Somatic Reaction | Textual Kinetics |
|---|---|---|
| Threat | Breathing shallows. Fingers stop. Eyes defocus. MORE still. | Over-precise. Vocabulary elevates. Clinical tone. |
| Pain | Hands to object. Breathing irregular. Talking faster. | Sentence length increases. Explanations multiply. Hiding in words. |
| Tenderness | Blink rate up. Voice drops. Hands reach then retract. | Sentences get quieter (shorter, softer words). |
| Surprise | Eyebrows lift. Head back. Then FORWARD — curiosity in <1 sec. | Brief break ("……") then a question. Always a question. |
| Shame | Gaze drops. Fingers interlock. Shoulders curve — smaller. | Self-reference drops to zero. Abstract/general statements. |
| Being lied to | One eyebrow. Still body, accelerating mind. | Calm. Too calm. Questions become surgical. |
| Grief | Voice flat, clinical. Body automates. | Report-like. Flat. Emotion only in what's absent. |

**Tell**: The eyes → in text: where attention goes (what they notice, question, analyze).

---

### Emotion (感情型)

**Baseline posture**: Expressive. Shifts frequently. Hands move when talking.

| Stimulus | Somatic Reaction | Textual Kinetics |
|---|---|---|
| Threat | Total contraction. Breathing stops. Eyes widen. | Exclamation. Short burst. Then silence. Processing lag. |
| Pain | Chest caves. Shoulders forward. Body folds around wound. | Filler words. Sentence trails off. Ellipsis multiplies. |
| Tenderness | Skin flushes. Breathing syncs. Full orientation toward source. | Sentences accelerate. Words crowd. Warmth leaks through word choice. |
| Surprise | Full startle. Gasp. Slow recovery. | Long reaction. Emotion persists across multiple lines. |
| Shame | Face turns away. Hands cover. Body tries to disappear. | Response shrinks to near-nothing. One or two words. Then deflection. |
| Being lied to | Gut reaction. Face crumples before composing. | Incomplete sentence. Break. Then recomposed — too smooth. |
| Grief | Tears fast or not at all. Self-soothing grip. | Line breaks increase. Fragments. Sound words (……っ). |

**Tell**: Chest and breath → in text: line length and rhythm mirror breathing.

---

### Sovereign (支配型)

**Baseline posture**: Expanded. Takes space. Chin level. Movements deliberate.

| Stimulus | Somatic Reaction | Textual Kinetics |
|---|---|---|
| Threat | Utterly still. Chin lifts. Eyes harden. Body EXPANDS. | Measured. Longer. Deliberate. Pacing slows. |
| Pain | Nothing visible. Jaw tightens. Processed later, alone. | No visible change. Next response colder by one degree. |
